LUMÉ Antalya — Beauty Studio

A responsive four-language website concept for a beauty studio in Antalya. It includes 32 services grouped into three directions, category-aware booking, WhatsApp contact, maps, a gallery, dual-currency prices and calm, accessible mobile navigation.

Адаптивная концепция сайта студии красоты в Анталии на четырёх языках. В ней 32 услуги в трёх направлениях, понятное бронирование по категориям, связь через WhatsApp, карта, галерея, цены в двух валютах и удобная мобильная навигация.

The project explores three visual directions: a calm premium version, a warmer joyful variation and LUMÉ Riviera — a more exclusive signature concept. Each version can be adapted to a real studio: brand, services, prices, contacts, photos, domain and booking channels.

В проекте исследованы три визуальных направления: спокойная премиальная версия, более тёплый радостный вариант и LUMÉ Riviera — эксклюзивная signature-концепция. Каждую версию можно адаптировать под действующую студию: заменить бренд, услуги, цены, контакты, фотографии, домен и каналы записи.

Usta Platform — Local Services

A responsive three-language marketplace concept connecting customers with local professionals. It includes more than 90 services, district-based requests, professional profiles, responses, favorites, internal chat and separate customer and professional journeys.

Адаптивная трёхъязычная концепция маркетплейса, соединяющего клиентов с местными специалистами. В проекте более 90 услуг, заявки по районам, анкеты специалистов, отклики, избранное, внутренний чат и отдельные сценарии для клиентов и исполнителей.

The current public version demonstrates the interface and interaction model. Authentication, a live database and real-time messaging are planned as the backend phase.

Текущая публичная версия демонстрирует интерфейс и модель взаимодействия. Авторизация, рабочая база данных и сообщения в реальном времени запланированы как следующий серверный этап.

How interactive can the site be?

Насколько интерактивным может быть сайт?

For a static site on free hosting, I can add responsive navigation, language and theme switching, tabs, accordions, search and filters, galleries, timelines, interactive charts, data tables, simple calculators, downloadable files, contact forms through external services and content loaded from JSON or public APIs.

Для статического сайта на бесплатном хостинге можно добавить адаптивную навигацию, переключение языка и темы, вкладки, раскрывающиеся блоки, поиск и фильтры, галереи, временные шкалы, интерактивные графики, таблицы данных, простые калькуляторы, файлы для скачивания, формы связи через внешние сервисы и загрузку данных из JSON или открытых API.

Technical boundaryТехнические ограничения

Secure user accounts, private databases, payment processing, complex administration panels and confidential data normally require a backend or specialized external service. Those features can be integrated, but they are beyond a purely static GitHub Pages site.

Защищённые аккаунты, закрытые базы данных, приём платежей, сложные панели управления и конфиденциальные данные обычно требуют серверной части или специализированного внешнего сервиса. Их можно интегрировать, но это уже выходит за рамки чисто статического сайта на GitHub Pages.

Fast changes
Быстрые изменения

Colors, typography, layout, sections, wording, images, links, languages and current information can be revised quickly while keeping the site lightweight and mobile-friendly.

Цвета, шрифты, расположение блоков, формулировки, изображения, ссылки, языки и актуальную информацию можно быстро менять, сохраняя лёгкость и удобство сайта на телефоне.
